# Phase H Follow-up: Buff 去重、上限修正与中央战场 HUD 优化

## Summary

先修正仿真数值，再调整中央战场展示。核心目标是：同技能同效果不再重复叠加；伤害结算默认启用副本战力上限；中央战场稳定展示增减益 HUD、技能总伤害/秒伤、主输出逐段伤害滚动列表，并移除底部四个统计胶囊。

## Key Changes

- 在模拟引擎效果管理中新增“同技能同效果覆盖规则”：
  - 作用范围：同一目标内按 `SourceSkillId + EffectId` 去重，跨施法者生效。
  - `Stackable: true` 的层数类效果继续保留现有 `MaxStacks` 逻辑。
  - 非层数效果重复施加时：仅当新效果强度 >= 旧效果，且新效果总时长 >= 旧效果剩余时长，才完整覆盖；否则本次施加记为 `SKIPPED/ignored`，旧状态不变。
  - 强度比较优先使用双方 `EffectPower`；否则按 `BuffEffects` 字段逐项比较，正向增益取更大为更强，负向破防取更小为更强。

- 调整属性上限默认语义：
  - 伤害计算默认启用上限；显式传入 `attributeCaps.EnableCaps=false` 才关闭。
  - 默认上限固定为：气血 400 万、真气 600 万临时全局默认、攻击 75 万、防御 50 万、爆伤 3000、绿点 900、易伤 120。
  - 真气“分职业 400/600 万”暂不硬编码猜测；等补充职业映射后再加 class/faction 级 resolver。
  - 同步计算器 UI 的气血上限展示为 400 万；防御保持 50 万。
  - Boss 破防仍保持现有范围：HUD/事件展示，不新增 Boss 防御伤害公式。

- 优化中央战场 HUD：
  - Buff/Debuff 方格缩小，只显示技能名前两个字和剩余时间。
  - 剩余时间小于 5 秒时变红。
  - hover/title 保留完整技能名、效果名、数值、剩余时间。
  - 小圆点按效果分类配色：绿点绿色、紫点紫色、破防深蓝、易伤蓝白、专注/巫咒橙色、加速红紫蓝渐变、爆伤黄色、真气蓝色、气血红色、攻击橘色。

- 重排中央战场内容：
  - 移除底部四个统计胶囊：当前均秒、战斗时间、当前回放、击杀点。
  - 技能总伤害和角色秒伤改为桌面宽度稳定可见的紧凑面板。
  - 新增主输出逐段伤害滚动列表，只显示 `zhushuang_dps` 的命中段：时间、技能、段数、伤害。
  - 排行和伤害列表随 `currentTimeMs` 回放进度变化，使用当前已发生命中数据。
