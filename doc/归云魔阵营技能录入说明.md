# 归云（GUI_YUN）魔阵营（MO）技能录入说明 —— A 方案（本体 + 独立被动卡）

> 交接文档：交给录入方按此录入 `web_app/public/game_data/skills.json` 的 `GUI_YUN.MO[]`。
> 方案已定（2026-09-18）：**与逐霜/涅羽等现有职业完全同构** —— 输出技能录**本体值**（不含造化/心法被动加成），造化被动录成独立卡片（`ActionType: "ZAO_HUA_PASSIVE"` + `ZaoHuaGrants`），运行时由引擎叠加。
> 这样技能速查页显示本体 + 被动独立卡，模拟训练场可自由切换四代/心法/被动启停。

## 通用约定

- 职业 `GUI_YUN`（归云，天脉远程法师），阵营 `MO`（魔）。归云为**输出职业，无团队增益**。
- 单位：固定攻击=点数；攻击比/气血比/真气比/爆伤=百分比数值（585 表示 585%）；施法/冷却=秒。
- 字段映射（与现有职业一致）：
  - 附加攻击比 → `SkillBonusAttributes.SkillAttackPercentBonus`
  - 附加固定攻击 → `SkillBonusAttributes.SkillAttackFixedBonus`
  - 附加气血比 → `SkillBonusAttributes.SkillHealthPercentBonus`
  - 附加真气比 → `SkillBonusAttributes.SkillManaPercentBonus`
  - 附加爆伤 → `SkillBonusAttributes.SkillCriticalDamagePercentBonus`
  - 施法 → `CastTime`；冷却 → `Cooldown`；`ActionType: "DAMAGE"`；`RequiredClass: "GUI_YUN"`；`Faction: "MO"`
  - 段数 → `MultiHitConfig.HitCount`
- **口径说明（重要）**：
  - 全部按**对怪口径**录入（项目只做 PVE），条件性"对怪翻倍/+X%"已折入本体对应字段，录入时不再区分。
  - **天书残卷增益是技能卡自带**（图内天书行），折入技能本体（如皓凝霜雪III 的 +25 攻击比、+3000 固攻、+25 爆伤）。天书不是造化被动，**不录独立卡**。
  - **造化/心法被动（穿林打叶II、岁寒II）不折算**，录成 2 张独立 `ZAO_HUA_PASSIVE` 卡（见下文），运行时叠加。
  - 暂不计入伤害公式的效果（引擎无对应字段，仅作技能说明保留）：技能命中率、暴击率加成、控制效果（虚弱/定身/眩晕）、急雨冰瀑持续 +3s。
- 🔴 **引擎前置需求**：多段技能存在"每段数值不同且非等差"（攻击比/固攻/气血比/爆伤都有），现有引擎只有线性递增（`ScalingAttribute`）与 `PerHitCharacterBonus` 两种，**必须先给引擎加"每段显式数组"支持**（如 `MultiHitConfig.PerHitOverrides: { [attr]: number[] }`，第 k 段取 `arr[k-1]`；Grant 叠加时对数组**逐段相加**），再按下方每段数组录入。
- 行云层数上限 **30 层**；岁寒II 的"每层行云 +2% 技能伤害 / +2.0% 本体攻击"按**满层常驻**折算成 Grant 攻击比 +60（现有职业同口径）。
