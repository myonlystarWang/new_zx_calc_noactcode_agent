### 4.2 本质

完整还原 = 职业 + 阵营 + 副本 + ~20 个属性数值 + 增益勾选 + 增益数值，数据本身几百字符。**纯前端只能压缩变短，无法凭空变短；真正「短」必须有服务端（短链/云端存储）。**

### 4.3 候选方案对比

| 方案 | 链接形态 | 长度 | 代价 |
|------|----------|------|------|

| 3. 混合 | 短链优先，完整链接兜底 | 短 | 部署一次，回退逻辑兜底 |

## 五、Worker 短链与 Pages 的结合（推荐方案）

### 5.1 方式对比

| 方式 | 说明 | 评价 |
|------|------|------|
| **A. Pages Functions（推荐）** | 代码放 `web_app/functions/`，随 Pages 一起部署，无需单独 Worker | 代码进 Git、一次部署、同源无跨域，最干净 |
| B. 独立 Worker + 域名路由 | 单独部署 Worker，控制台给 `raddishlab.tech/s/*` 配路由 | 多一个部署单元，控制台手工配置，不推荐 |

### 5.2 推荐架构（方式 A）

```
web_app/
├── functions/                    # 新增，随 Pages 自动部署
│   ├── api/shorten.ts            # POST：接收完整配置 → 存 KV → 返回短码
│   └── s/[code].ts               # GET：查 KV → 302 跳到完整链接
├── src/                          # 前端（新增 shareLink.ts / exportImage.ts 等）
└── dist/                         # 构建产物
```

**生成链路**：点「复制链接」→ 前端构造完整压缩链接 → `POST /api/shorten`（同源）→ 返回短码 → 复制 `raddishlab.tech/s/Ab3xZ` → 提示「已复制」

**恢复链路**：对方打开短链 → `s/[code].ts` 查 KV → 302 到 `#/calculator?class=..&a=..` 完整链接 → 前端 `CalculatorDeepLinkRestore` 解析并恢复配置

**容错**：短链服务不可用时，自动回退复制完整压缩链接——短链是增强，不是单点依赖

### 5.3 需要的 Cloudflare 控制台操作（一次，约 2 分钟）

1. 创建一个 KV 命名空间（如 `zx_shortlinks`）
2. 在 Pages 项目设置中绑定该 KV（绑定名 `SHORTLINK_KV`）
3. （可选）确认域名 `raddishlab.tech` 已挂 Cloudflare

## 六、最终实施计划（待确认后执行）

1. **依赖**：安装 `html2canvas`（动态 `import()` 按需加载，不进主包、不拖慢首屏）

   - 解析 + 校验（字段完整性、范围），供恢复组件使用
4. **新增 `CalculatorDeepLinkRestore.tsx`**（null 渲染组件，App.tsx 挂载）
   - 仅首次挂载解析恢复：职业（校验存在）、阵营（校验合法）、属性（合并默认结构防缺字段）、增益（过滤不存在 id）、副本
   - 非法参数自动忽略，幂等执行一次，不影响后续手动操作
5. **修改 `ResultsSection.tsx`**
   - 「副本战力分析」标题行右侧加两个按钮（图标+中文，沿用 Step 7 风格）：
     - 📷「导出截图」：动态加载 html2canvas → 截当前正面卡片内 `.zx-card`，文件名 `副本战力_副本名_日期.png`，导出中显示「导出中…」
     - 🔗「复制链接」：短链优先 + 完整链接兜底，反馈沿用 ✓「已复制」2 秒恢复
   - 窄屏按钮文字缩短（「截图」「链接」）防挤压

### 6.2 后端（Pages Functions）

6. **新增 `functions/api/shorten.ts`**：POST 完整配置 → 生成短码（如 6 位随机/base62）→ 存 KV（key=短码，value=完整链接，含 TTL）→ 返回 `{ code }`
7. **新增 `functions/s/[code].ts`**：GET → 查 KV → 302 到完整链接；未命中返回 404

### 6.3 验证

## 八、已知风险与对策

| 风险 | 对策 |
|------|------|
| html2canvas 不支持 backdrop-filter（毛玻璃） | 截图瞬间给卡片垫纯色底，截完恢复；深色底兜底 |
| html2canvas 对 3D 变换支持差 | 只截正面恒等变换的卡片，不截 3D 容器 |
| 完整链接超长 | 压缩编码（180-250 字符）+ 短链（25 字符）双轨 |
| 短链服务不可用 | 复制链接自动回退完整链接，功能不中断 |
| URL 非法参数/损坏 base64 | 解析层防御清洗，不白屏、不污染状态 |
| KV 短码冲突 | 短码生成带重试/碰撞检测 |
