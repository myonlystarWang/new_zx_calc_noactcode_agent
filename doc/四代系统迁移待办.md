## 旧建模方式说明

- **方式A**：主动四代，条目名写死品质（如"·曦日"），数值写死，不能切品质。
- **方式B**：被动四代，四代实体缺失，把品质效果以 `FourthGenPresets` 挂在**被影响的普通技能**上，靠"给目标技能选品质"隐式触发。
- **方式C**：四代独立条目（伤害/debuff），但没有品质字段，数值单一。

**迁移目标**：每个四代技能建为独立实体条目（分阵营、带 FourthGenSlot）；作用本技能用 `FourthGenPresets`、作用其他技能用 `FourthGenGrants`；玩家通过 `equippedFourthGen` 佩戴并选品质。迁移后删除旧的隐式投影/写死品质条目。

## 迁移注意事项

1. 迁移前后必须用 regression_test 逐职业对比，确保同品质下伤害结果一致（等价重构）。
2. 方式B迁移后，arena 里"给每个输出技能选品质"的旧交互要同步切到"佩戴四代实体"。
3. 一个四代影响多个技能时，在实体的 FourthGenGrants 里用多个 grant / 多个 TargetSkillIds 表达，不要拆散。
4. 迁移与新职业录入分开提交，便于回溯。
5. 本文件在全部旧建模迁移完成后归档/删除。
6. **COMMON 通用阵营**：四代效果跨阵营（仙/佛/魔）相同时，建 `Faction="COMMON"` 实体，Grants 的 TargetSkillIds 一次列出各阵营目标，当前玩家只命中本阵营；引擎 getFactionSkillPool 与前端 getFactionSkills 都会合并 COMMON，fourth_gen 对 COMMON 实体命中不到的跨阵营目标静默跳过。逐霜为首个 COMMON 先例。

## 四、单次计算路径四代支持：已实现（2026-09-15，方案 A，详见 change_log 1.0.8）

- **最终方案（用户拍板）**：单次路径（属性战力计算器 / agent_tool 的 normalize）**不加四代槽位与品质 UI**，固定按理论满配、最高品质**曦日**计算，并为「战斗满状态」技能生成峰值变体。
- **实现入口**：引擎 `single_calc.ts → buildSingleCalcSkills(classFactionSkills, faction)`：
  1. 合并本阵营 + COMMON 并深拷贝；
  2. `applyPeakFourthGen` 固定 XI_RI 套用全部四代 Grants（自动扫描、零职业特例；单次为逐技能理论满配，绕开 3玄烛1赤乌槽位校验；COMMON 跨阵营未命中目标静默跳过）；
  3. 只保留 DAMAGE 输出技能；
  4. `PEAK_VARIANT_RULES` 登记「战斗满状态」峰值变体（首个为逐霜苍龙·龙怒：法宝+1 鹰扬 10 级、满层全附加，Variant=LONGNU，名加后缀·龙怒）。
- **两条路径关系**：训练场 / agent sim（assembler + Actor + combat_loop 时间轴）仍是完备实盘；单次是理论满配快照；二者共用同一个 calculateDamage，公式零差异。
- **推广方式**：四代满配对全职业自动生效、无需写代码；只有类似龙怒的「战斗满状态峰值」需要在 PEAK_VARIANT_RULES 为该职业加一条规则。
- **遗留（未来增强）**：若日后伤害计算页面加上四代槽位/品质选择 UI，则改为读取玩家实际佩戴与品质（复用 applyEquippedFourthGen），替代当前固定曦日满配；并可让玩家自选是否计入龙怒等满状态峰值。（原 2026-09-13「单次路径暂不做」的决定已被本节取代。）

## 五、逐霜 · 心法「乘时而化」（遗留方案，2026-09-15 登记，本次不实现）

- **来源**：流波惊变技改，逐霜心法技能「乘时而化」。
- **效果**：点了该心法后延长两类效果持续时间：①玄烛·云蒸霞蔚（ZS_COMMON_FG_YZXW）的真气增加效果；②清啸横朔（ZS_*_SKILL_QXHS）的攻击/技能专注效果（初步秒数：云蒸 12→16、噬血 3→8、太极 15→24、玄清 15→24，准确 EffectId 与点前/点后秒数待取齐游戏内数据）。
- **现状缺口**：引擎没有「心法」字段/系统（types.ts 无对应类型，profile 无法表达是否点了某心法）。
- **建议实现方案（未来）**：
  1. profile 增加被动心法开关（类似 equippedFourthGen，类被动、不进技能循环），如 `equippedXinfa: ["ZS_XINFA_CHENGSHIERHUA"]`；
  2. assembler / actor 构建时，若点了乘时而化，对指定 EffectId 的 Duration 做固定延长（用一张「原 Duration → 新 Duration」配置表表达，可挂在心法实体的 Grants 上）；
  3. 与四代品质、阵营（仙云蒸爆伤）正交，互不覆盖。
- **待补数据**：乘时而化影响的全部 EffectId 及各效果点前/点后准确秒数（用户尚未给全，拿到后再实现）。
