# 诛仙3 寻宝天行与游戏原生道具配色系统分析规范

## 1. 概述与背景

诛仙3 官方道具交易平台——**寻宝天行**（`xunbao178.com`）与游戏原生客户端共享完全同一套道具元数据解析与样式规范体系。通过反编译寻宝天行实机页面（`showDetail.gsp`）、核心解析脚本（`common.js`、`role.js`）及真实角色全量道具描述 XML（覆盖 700+ 件真实武器、防具、佩章、轩辕策、饰品、阵灵与法宝），本项目提炼并沉淀了全生命周期通用的**游戏原生道具配色系统与渲染规范**。

## 2. 核心控制符编码机制

游戏客户端及寻宝天行中所有道具的描述字段（`desc`）均基于 Caret 控制符流式解析：

- `^RRGGBB`：6 位十六进制色彩前缀，用于设定随后文本的字色。
- `\r`：换行符（在 HTML 中解析为 `<br/>`）。
- `\n`、`\t`：制表或多余格式控制符（通常被滤除或转为空格）。
- `^^`：转义字符，输出字面量 `^`。

寻宝天行核心解析算法（`common.js` 原生实现）：
```javascript
function parseItem(text) {
    var s = $.trim(text);
    var array = [];
    var lastColor = "ffffff";
    array.push("<font style='color:#" + lastColor + "'>");
    var re = /\^\w{6}/;
    for (var i = 0; i < s.length;) {
        var c = s.charAt(i);
        var temp = s.substring(i, i + 7);
        var result = temp.match(re);
        if (result) {
            array.push("</font><font style='color:#" + temp.substring(1) + "'>");
            lastColor = temp.substring(1);
            i = i + 7;
        } else if (c == '\\' && s.charAt(i + 1) == 'r') {
            array.push("</font><br/><font style='color:#" + lastColor + "'>");
            i = i + 2;
        } else {
            array.push(s.charAt(i));
            i++;
        }
    }
    array.push("</font>");
    return array.join("");
}
```

## 3. 武器与防具神隐装备体系（修武 / 昭武 / 彰武 / 混虚系列）

### 3.1 蕴灵与炼器强化色阶

对于神隐装备（修武、昭武、彰武、混虚修武、混虚昭武、混虚彰武），**首行装备名称与蕴灵等级共享完全一致的蕴灵品阶字色**。

## 11. 1:1 游戏原生全量技能卡片体系规范

### 11.1 数据基座与色彩渲染架构
- **数据源**：`all_skills_curated.json`，涵盖诛仙3全门派、神通、造化、天书共 5,927 个全量技能。
- **色彩符解析器**：通过 `parseGameColorSegments` 实时解析游戏原生 `^RRGGBB` 颜色标识符（如 `^ffffff` 纯白、`^ffcb4a` 琥珀黄、`^11aaff` 苍蓝、`^11ff11` 荧绿、`^cc33ff` 幽紫、`^ff2222` 赤红），完整还原游戏原生彩色技能说明与排版换行。

### 11.2 等级推演器 (Skill Stepper)
- 技能卡片顶部内嵌等级推演控制栏：
  - **当前等级 / 最大阶数**：如 `10 / 10`、`11 / 11`、`20 / 20`。
  - **步进按钮**：`[-1]` 降级、`[+1]` 升级。
  - **极值快捷跳转**：`[初始]`（一键切换至 1 阶查看基础属性）、`[满阶]`（一键切换至满阶查看巅峰属性）。
- 切换等级时实时联动更新当前阶位的彩色原生技能描述文本。

### 11.3 AI 对话与多候选流式选择器集成
- 用户输入技能名（如 `苍龙啸`、`神剑御雷真诀`、`重击`）或组合词（如 `逐霜 苍龙啸`、`逐霜 技能`）时，AI 引擎自动匹配核心技能与神通分支。
- 命中单技能时直接返回 1:1 游戏原生技能卡片。
- 命中多技能候选时（如 `苍龙啸` 主技能与仙/魔/佛三代神通），挂载 `CandidateSelectorBar`，支持横向滑轮滚动、一键展开平铺网格，点击任意候选实时切换呈现对应的 1:1 原生技能视图。
