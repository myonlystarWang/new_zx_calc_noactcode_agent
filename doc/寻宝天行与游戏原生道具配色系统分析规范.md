# 诛仙3 寻宝天行与游戏原生道具配色系统分析规范

## 1. 概述与背景

诛仙3 官方道具交易平台——**寻宝天行**（`xunbao178.com`）与游戏客户端共享同一套道具元数据解析与样式体系。通过抓取并反编译寻宝天行实机页面（`showDetail.gsp`）、核心解析脚本（`common.js`、`role.js`）及真实角色全量道具描述 XML（700+ 件真实装备/法宝/消耗品），我们提炼并沉淀了本项目全生命周期通用的**游戏原生道具配色系统与渲染规范**。

## 2. 核心控制符编码机制

游戏及寻宝天行中所有道具的描述字段（`desc`）均基于 Caret 控制符解析：

- `^RRGGBB`：6 位十六进制色彩前缀，用于设定随后文本的字色。
- `\r`：换行符（在 HTML 中解析为 `<br/>`）。
- `\n`、`\t`：制表或多余格式控制符（通常被滤除或转为空格）。
- `^^`：转义字符，输出字面量 `^`。

寻宝天行核心解析算法（`common.js`）：
```javascript
function parseItem(text) {
    var s = $.trim(text);
    var array = [];
    var lastColor = "ffffff";
    array.push("<font style='color:#" + lastColor + "'>");
    var re = /\^\w{6}/;
    for (var i = 0; i < s.length;) {
        var c = s.charAt(i);
        var temp = s.substring(i, i + 7);
        var result = temp.match(re);
        if (result) {
            array.push("</font><font style='color:#" + temp.substring(1) + "'>");
            lastColor = temp.substring(1);
            i = i + 7;
        } else if (c == '\\' && s.charAt(i + 1) == 'r') {
            array.push("</font><br/><font style='color:#" + lastColor + "'>");
            i = i + 2;
        } else {
            array.push(s.charAt(i));
            i++;
        }
    }
    array.push("</font>");
    return array.join("");
}
```

## 3. 蕴灵与炼器强化色阶（修武 / 昭武 / 彰武 / 混虚全系列）

对于神隐装备（修武、昭武、彰武、混虚修武、混虚昭武、混虚彰武），**首行装备名称与蕴灵等级括号共享完全一致的蕴灵品阶字色**。

| 蕴灵等级区间 | 游戏色彩代码 | 对应十六进制 | 色彩视觉描述 | 实机表现例 |
|:---|:---|:---|:---|:---|
| **+0 ~ +10** | `^d1e4f7` | `#d1e4f7` | 淡淡的苍白微紫 / 霜白色 | `忘宵荡魄腕·修武（男）（蕴灵 +9）` |
| **+11** | `^00ff00` / `^11ff11` | `#00ff00` | 碧绿色 / 翠绿 | `绝峰·昭武（蕴灵 +11）（灌注+10）` |
| **+12** | `^3aa6f9` | `#3aa6f9` | 湛蓝色 / 天青纯蓝 | `渊幽洞渊冠·昭武（女）（蕴灵 +12）` |
| **+13** | `^f8f64b` | `#f8f64b` | 明黄色 / 灿金明黄 | `百变·昭武（蕴灵 +13）（灌注+10）` |
| **+14** | `^aa32ff` / `^cc33ff` | `#aa32ff` | 幽紫色 / 炫光紫 | `蕴灵等级+14` 醒目标识 |
| **+15** | `^ff0000` / `^ff2222` | `#ff0000` | 炽红色 / 极道赤红 | `贯海·混虚彰武（蕴灵 +15）（灌注+10）` |

> **关键规则**：
> 1. 首行不仅是 `（蕴灵 +15）` 变红，**装备本体名称（如“贯海·混虚彰武”）也会同步继承该红色**。
> 2. 从 +0 到 +15，视觉梯度为：淡白紫 -> 碧绿 -> 湛蓝 -> 明黄 -> 幽紫 -> 炽红。

## 5. Tooltip 容器排版与视效规范

为 1:1 还原游戏与寻宝天行原貌：
- **容器背景**：极深蓝黑半透明背景（`rgba(8, 12, 20, 0.95)`）。
- **边框风格**：1px 细微深蓝灰色边框（`#1e293b`），带极微内发光（`box-shadow: inset 0 0 12px rgba(25, 45, 75, 0.3)`）。
- **字体族**：`"SimSun", "宋体", "Microsoft YaHei", sans-serif`。
- **字号与行距**：字号 `12px`，单行行高 `20px`（`line-height: 20px`），字间距 `0.5px`。
- **布局流**：严格保持纵向流动，两端对齐或左对齐，去除过度的卡片嵌套和多余胶囊。
