# Phase H: 副本模拟训练场 UI/UX 重设计规划

## Summary

将【副本模拟训练场】从当前“左配置 + 右报告页签”的工具页，重构为 PC 优先的“战斗中复盘 cockpit”。

默认首屏是三段战斗 HUD：左侧 6 人队伍框，中间 Boss 战场，右侧上下文抽屉入口，底部常驻时间轴与技能栏。资料查询、配置编辑、分析图表和 A/B 对比都通过抽屉展开，不抢占主战场。移动端只保证可用，不作为本轮核心验收目标。

## Key Changes

- 主布局改为一屏 cockpit：
  - 左：6 人队伍框，1 主输出 + 5 辅助，显示职业、阵营、关键 Buff 状态、技能启用状态。
  - 中：Boss 战场主视图，包含 Boss 大血条、击杀时间、当前回放时间、关键伤害反馈、战斗状态提示。
  - 右：上下文抽屉入口，点击 Boss、队友、技能、时间轴节点后打开详情或编辑。
  - 底：战斗复盘时间轴，显示主输出施法、我方 Buff、Boss Debuff、伤害命中、Boss 死亡点。

- 配置交互改为“点击槽位开抽屉”：
  - 点击队伍槽位：编辑职业、阵营、辅助属性，并查看该角色技能。
  - 点击 Boss：选择副本/Boss、覆盖血量、查看 Boss 属性。
  - 点击技能栏/策略区：编辑法宝栏、固定循环或手动时间轴表格。
  - 修改配置后不自动重跑，只标记“结果已过期”，玩家点击启动后重新仿真。

- 资料查询抽屉：
  - 支持全局搜索职业、阵营、技能、Buff/Debuff、Boss。
  - 搜索支持中文名、JSON ID、手工维护的常用拼音别名；不引入完整拼音库。
  - 任意队伍槽、技能、Boss、时间轴状态都能一键打开对应资料详情。
  - 暂禁用、部分启用、已参与结算的技能必须有明确状态标记。

- 分析抽屉：
  - 主屏只保留核心战斗反馈。
  - 详细 DPS 曲线、Boss 血线、技能占比、Buff 覆盖率、事件日志、A/B 对比进入分析抽屉。
  - 继续复用 Recharts，不新增图表依赖。

- 视觉方向：
  - 取消“量子、全息、投影”等科幻表达。
  - 使用原创抽象战场资产：暗色副本背景、阵法纹理、Boss 剪影或图标，不使用官方游戏素材。
  - 保留 Tailwind + lucide + Recharts 技术栈；资产放入 Web public 资源目录，并提供 CSS fallback。

## Interfaces And State

- 新增或重构 Arena 层状态：
  - `activeDrawer`: 当前打开的抽屉类型。
  - `selectedEntity`: 当前查看的 Boss、角色、技能、Buff、时间轴事件。
  - `isResultStale`: 配置变更后标记当前仿真结果已过期。
  - `currentTimeMs`: 继续作为回放统一时间源。
  - `searchQuery/searchTokens`: 资料查询用，包含中文、ID、拼音别名。

- 不改模拟引擎输入协议，只在 UI 组装层保持：
  - 暂禁用辅助技能继续展示，但不进入默认仿真。
  - 6 人队伍先完整落地，12 人只预留布局和数据结构扩展点。

## Test Plan

- 构建与类型：
  - `npm run check:all`
  - `npm run test:f`

- UI 手工验收：
  - PC 1440px+ 首屏无页面级纵向滚动，内部面板可滚动。
  - 从空白状态完成：选 Boss、配队伍、调策略、启动仿真、回放时间轴。
  - 修改任一关键配置后，结果显示“已过期”，不会自动重跑。
  - 点击 Boss、队友、技能、Buff、时间轴节点均能打开正确详情抽屉。
  - 中文、ID、常用拼音别名均能搜到对应技能或 Boss。
  - 暂禁用技能可查阅，但不会显示为参与当前仿真结算。

- 视觉验收：
  - 首屏第一眼应像“正在进行副本战斗复盘”，不是后台表单页。
  - 不再出现“量子/全息”等科幻 UI 文案。
  - 文本不重叠，按钮和技能格尺寸稳定。

## Assumptions

- 本轮以 PC 为主，移动端只做基础可用。
- 第一版只实现 6 人训练场，12 人后续扩展。
- 不使用官方《诛仙3》素材；允许生成原创抽象战场资产。
- 不引入拖拽库；时间轴第一版是可视轨道 + 表格编辑。
- 后续实现时同步生成对应 `doc/phase H task.md` 和 `doc/phase H walkthrough.md`。
