# Phase H Walkthrough: 副本模拟训练场 Cockpit 重设计

## 执行过程

1. 复核 Phase H 计划，并保留模拟引擎输入协议不变。
2. 将 `SimulationArena.tsx` 从“左配置 + 右报告”改为 cockpit：
   - 左侧：6 人队伍槽，显示职业、阵营、技能结算状态。
   - 中间：Boss 血条、战场资产、回放时间、核心指标、启动仿真与过期提示。
   - 右侧：Boss、策略、分析、资料查询入口。
   - 底部：回放时间轴、所有事件点轨道。
3. 将原有 `StrategyEditor` 与 `SimulationReport` 迁入抽屉复用；主输出、队伍与 Boss 抽屉已改为 Arena 内部统一风格面板。
4. 新增资料查询抽屉，搜索 token 覆盖中文名、JSON ID 与常用拼音别名。
5. 新增原创抽象战场背景 `web_app/public/arena/arena-bg.svg`。
6. 调整 `App.tsx`，训练场 tab 使用固定一屏容器并隐藏 Footer。
7. 清理训练场可见 UI 中旧的“量子/全息/投影/矩阵”表达。
8. 根据截图反馈修补：
   - Boss 战场背景可见度不足：调亮 `arena-bg.svg`，降低组件遮罩。
   - Boss 战场底部指标被裁切：收紧中间战场高度与 Boss 圆形尺寸。
   - “最新命中”不符合需求：替换为技能总伤害/占比榜与角色秒伤榜。
   - 当前均秒不随时间轴变化：改为基于 `currentTimeMs` 与当前已发生命中实时计算。
   - 三个配置抽屉不统一：重做主输出、队伍与 Boss 抽屉。
   - 底部重复技能栏：移除底部技能栏，右侧只保留“所有事件点”。
   - 英文字段过多：在技能详情、事件节点、时间轴标题中加入 UI 层中文化映射。
9. 根据新增要求修补：
   - 计算器页副本伤害详情过滤非输出技能。
   - 用户可见项目名改为“诛仙3副本战斗实验室”。
10. 根据新一轮截图反馈继续修补：
   - 移除 `.zx-card` 角标 hover 装饰，避免综合战力卡片左上/右下出现突兀方框。
   - 底部“所有事件点”暂不显示死亡点轨道与死亡点节点。
   - 将训练场回放总时长改为 summary、Boss 击杀点、最后事件、最后命中的最大值；默认场景由 18.66s 修正为 22.126s 回放终点。
   - 中央战场加入主输出增益与 Boss 减益 HUD，按当前回放时间重建活跃效果，显示关键数值与倒计时。
   - 补充技能类型、状态字段和命中详情中文化，降低英文枚举与实例 ID 暴露。

## 关键行为

- 默认仿真仍排除当前暂禁用辅助技能；这些技能仍可在队伍槽和资料抽屉中查阅。
- 配置修改会设置 `isResultStale=true`，保留旧结果供对照，不自动重新计算。
- 重新点击“启动仿真”后刷新结果并清除过期状态。
- 分析抽屉继续承载 DPS 曲线、Boss 血线、技能占比、事件日志与 A/B 对比。
- 辅助技能的四代品质、法宝+1 与少量 variant 通过 `skillOverrides` 进入模拟装配。
- 计算器页的副本伤害详情只计算 `ActionType` 为空或 `DAMAGE` 的技能，避免 Buff/Debuff 混入输出表。
- Boss “已击杀”只在 `currentTimeMs >= killedAtMs` 后显示；回放终点时若已击杀，Boss 血量显示为 0。
- 主输出增益/Boss 减益 HUD 从 `BUFF_APPLY`、互斥替换与 `BUFF_EXPIRE` 事件重建，不改变模拟引擎输入协议。
